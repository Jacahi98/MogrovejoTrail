# Mogrovejo Trail

Web oficial de Mogrovejo Trail, una carrera de trail running en Mogrovejo,
Cantabria (comarca de Liébana), con tres modalidades: 10K Trail, Andarines y
carreras infantiles. Próxima edición: 25 de julio de 2026. Sitio
multilenguaje.

## Qué tiene la web

- Presentación de las tres modalidades, con enlace al track del recorrido de
  10 km en Wikiloc, mapa y perfil de elevación.
- Reglamento, avituallamiento, información de acceso/aparcamiento y llamada a
  voluntarios.
- Pedido de camisetas, galería de fotos y vídeo promocional.
- Resultados de ediciones anteriores (enlazan a sportmaniacs.com — no hay
  base de datos ni inscripción propia en el sitio).
- FAQ y página de contacto.

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion · Sharp (imágenes) ·
Vitest + Testing Library (tests)

## Desarrollo local

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
